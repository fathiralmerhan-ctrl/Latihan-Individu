# Academic Performance System

Aplikasi sederhana berbasis PHP untuk menghitung 
nilai mata kuliah, Indeks Prestasi Semester (IPS), 
dan batas maksimal pengambilan SKS semester berikutnya.

## Fitur
- Array multidimensi mata kuliah.
- Konversi nilai angka menjadi nilai huruf.
- Perhitungan bobot nilai.
- Penentuan status kelulusan.
- Penanda merah untuk mata kuliah mengulang.
- Perhitungan IPS.
- Penentuan maksimal SKS semester berikutnya.

## Teknologi
- PHP
- HTML
- CSS
- XAMPP

## Cara Menjalankan
1. Clone repository.
2. Pindahkan folder project ke htdocs.
3. Jalankan Apache melalui XAMPP.
4. Buka browser.
5. Akses http://localhost/latihan-individu/
